## Hosting bei GitHub Pages

Diese Website wird mit GitHub Pages von GitHub, Inc. (88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA) gehostet. Beim Aufruf der Seite verarbeitet GitHub technische Daten, zum Beispiel deine IP Adresse, Datum und Uhrzeit, die aufgerufene Seite und den Browsertyp, in Server-Logfiles. Laut GitHub können Daten in die USA übermittelt werden. Details findest du in der [Datenschutzerklärung von GitHub](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement).

Rechtsgrundlage ist mein berechtigtes Interesse an einer sicheren und zuverlässigen Darstellung dieses Blogs (Art. 6 Abs. 1 lit. f DSGVO).

## Was diese Website nicht tut

- Sie setzt keine eigenen Cookies und nutzt keinen Tracking- oder Analysedienst.
- Sie hat keine Kommentarfunktion und keine Formulare.
- Die Suche läuft in deinem Browser. Deine Suchbegriffe werden weder an mich noch an einen Server gesendet.
- Sie lädt keine Schriftarten, Skripte oder Bilder von Dritten.

## Externe Links

Links zu LinkedIn, GitHub, IDUG und anderen Seiten führen zu Diensten mit eigenen Datenschutzerklärungen. Sie verarbeiten Daten erst, wenn du dem Link folgst.

Wenn du mir schreibst, zum Beispiel auf LinkedIn, per E-Mail oder in einem GitHub Issue, verarbeite ich deine Nachricht und die darin enthaltenen Daten nur, um dir zu antworten. GitHub Issues sind öffentlich. Bitte schreibe dort keine persönlichen oder vertraulichen Daten hinein.
